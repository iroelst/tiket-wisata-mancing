Riwayat transaksi

Pengaturan printer Bluetooth

RPP02N biasanya memakai Bluetooth Classic SPP. Chrome Android tidak dapat membuka koneksi SPP secara langsung dari halaman HTML. Jika printer Anda muncul di aplikasi printer Android (misalnya aplikasi pendamping yang biasa digunakan), gunakan tombol cetak melalui aplikasi tersebut. Tombol BLE di bawah hanya untuk printer yang mendukung Bluetooth Low Energy.

Belum ada koneksi Bluetooth.

Untuk RPP02N: pasangkan printer dari Pengaturan Bluetooth HP, lalu tekan Pilih / sambungkan RPP02N di sini.

Cara cetak RPP02N (Bluetooth Classic)

  1. Pasangkan RPP02N melalui pengaturan Bluetooth HP.
  2. Buka aplikasi printer Android yang biasa digunakan untuk RPP02N.
  3. Pilih transaksi lalu tekan Cetak tiket.
  4. Jika aplikasi printer menyediakan fitur menerima teks/gambar dari aplikasi lain, pilih aplikasi tersebut dari menu Bagikan.
